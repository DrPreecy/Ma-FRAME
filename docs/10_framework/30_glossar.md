# Glossar (Entwurf)

| Begriff | Arbeitsdefinition nach Quellen | Status / Hinweis |
| --- | --- | --- |
| Äußerer Input (`y`) | Externe Perspektiven, Recherche, Gegenhypothesen, Meinungen und Kontext. | Bedeutung je Formel präzisieren. |
| Drei-Staaten-Modell | Bild für überregulierte, absolut freie und unterstützend strukturierte Systeme. | Philosophische Metapher aus ITP. |
| Execution-Gleichung | `Blueprint_Spec == Output_Build`; Soll-Bauplan und gebauter Zustand stimmen überein. | Phase IV. |
| GUFP | Im ITP sowohl „Gesunder, unvoreingenommener, freier Prozess“ als auch „Get / Understand / Form / Prove“. | Doppeldeutigkeit ausdrücklich offen. |
| Ideen-Produktprofil (`A`) | Unverbindliche Zusammenfassung des ursprünglichen und vertieften inneren Inputs nach Phase I. | Abschluss-/Detaillierungsmaß unklar. |
| Innerer Input (`x`) | Eigene Vision, Wünsche, Intentionen und gedanklicher Kontext. | Rückverfolgbarkeit im Ergebnis schützen. |
| Leitstrahl | Gerichtete, übergeordnete Orientierung vom Konzept in Richtung Ausführung. | Nicht streng linear; siehe dynamisches Routing. |
| Operator | Person, die Ziel und Auftrag bestimmt, prüft und freigibt; nicht von der KI abhängig. | Rollenbild aus KI-Bericht/ITP. |
| Perfektionsblindheit | Blockade durch übermäßige Perfektion oder Messbarkeit; systemische Struktur soll entlasten. | Definition und Erkennungsmerkmale offen. |
| `PB` / geteilte Bausteine | Informationen, die zugleich Produkt- und Projektplan betreffen. | Rechte und Änderungsfluss offen. |
| `Protected_Value` / Save State | Gesicherter aktueller Arbeitsstand, vor unbefugtem Tool-/Agenten-Überschreiben geschützt und durch den Nutzer veränderbar. | Schutzmechanismus zu konkretisieren. |
| Räume | Spezialisierte Arbeitsbereiche in Phase III, die über gemeinsame Informationen vernetzt sind. | Nicht zwingend lineare Reihenfolge. |
| Vibe-Coder | In den Quellen ein intuitiv arbeitender, aber planloser Promptender; das Framework soll Orientierung geben, ohne die Arbeitsweise abzuwerten. | Umgangssprachlicher Quellenbegriff. |
| `x = y` | ITP-Formel zur Balance von innerem und äußerem Input; KI-Bericht deutet sie als funktionale Rückverfolgbarkeit. | Keine mathematische Gleichheit; verbindliche Lesart offen. |
